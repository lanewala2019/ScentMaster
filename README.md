ScentMaster is a hardware/software project for a device that offers a sequence of scents/odors that can be customized (up to a point!) by device subscribers. All subscribers must use official scent cartridges to conform to legal liability constraints because of the nature of scents that are generated.

Scents used can be controlled through an API that allows scents to be programmatically generated, e.g., in role-playing computer games. ScentMaster thus allows yet another dimension into the world of computer games.

The entire repository allows for the creation of hardware and software components needed in order to create this device.
